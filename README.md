## 🎬 核心功能

### 📂 一键上传，自动解析

支持 **PDF / Word / 图片** 格式，系统自动提取文字内容。上传后 AI 自动识别当事人信息、梳理时间线。

### 🪜 五阶段智能生成

每一步都可独立执行、修改、重新生成，**您始终掌控全局**：

1. **案件梳理** — 提取当事人、事实经过、时间线、证据清单
2. **法律分析** — 分析法律关系、适用法律、有利/不利因素
3. **争议归纳** — 梳理核心争议焦点、各方主张
4. **文书生成** — 生成起诉状/答辩状/代理词等 9 种文书
5. **审查优化** — 形式审查 + 实体审查 + 多模型交叉验证

> 💡 每一步都可以：编辑办案思路重新生成 · 直接修改内容 · 查看历史版本并回滚

### ✏️ 红线对比（类 Word 修订模式）

AI 修改后，系统用 **红色删除线** 标出删除内容，**绿色下划线** 标出新增内容——和 Word 修订模式一模一样，您一眼就能看出 AI 改了哪里。

### 🤖 AI 交叉验证

选中任意文字，可使用：
- **润色** — 让文字更专业严谨
- **补充法律依据** — 自动插入相关法条引用
- **对方律师挑刺** — 模拟对方律师找出逻辑漏洞
- **法官风险评估** — 从裁判者角度指出风险点
- **核查法条** — 验证引用的法条是否现行有效

### 📄 法院标准排版

导出 Word 时可选择：
- **标准排版** — 四号仿宋，28磅行距
- **法院严格格式** — 标题方正小标宋简体二号，正文仿宋_GB2312 三号，固定值 28 磅行距

### 🔒 一键脱敏

点击「🔒 一键脱敏」按钮，系统自动替换：
- 身份证号 → [身份证号-1]
- 手机号 → [手机号-1]
- 当事人姓名 → 甲方/乙方
- 统一社会信用代码 → [信用代码-1]

导出 Word 时自动还原为真实信息。

### ⚡ 极速生成

不想走完整流程？直接在首页点击「⚡ 极速生成」，粘贴案情描述，选择文书类型，一键生成。

## 🚀 快速开始

### 方式一：Docker 一键部署（推荐，无需安装任何环境）

```bash
git clone https://github.com/StanlySGY/LegalDocGen.git
cd LegalDocGen
docker-compose up -d
```

打开浏览器访问 **http://localhost:3000** 即可使用。

### 方式二：手动安装

<details>
<summary>点击展开手动安装步骤</summary>

**前置条件：** Python 3.11+、Node.js 18+

```bash
# 1. 克隆项目
git clone https://github.com/StanlySGY/LegalDocGen.git
cd LegalDocGen

# 2. 配置 AI 模型（在系统界面「助手配置」中添加，也可预设）
cp backend/.env.example backend/.env

# 3. 启动
chmod +x start.sh
./start.sh
```

- 前端界面：http://localhost:5173
- 后端 API：http://localhost:8002

## 🔒 安全与隐私

| 保障措施 | 说明 |
|----------|------|
| **完全本地部署** | 所有数据存储在您本地数据库，不经过任何第三方服务器 |
| **不收集数据** | 本系统不收集、不上传任何用户数据 |
| **API 直连** | 调用 AI 模型时，案件内容直接发送至您配置的大模型服务商 |
| **一键脱敏** | 上传材料后可自动替换身份证号、手机号、姓名等敏感信息 |
| **开源透明** | 代码完全开源，可自行审计安全性和隐私保护措施 |

> ⚠️ **建议**：处理涉密案件时，请使用自建的大模型服务或本地模型（如 Ollama）。
