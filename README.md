# 法律文书智能生成与审查系统

## 快速开始

### 1. 配置环境变量
```bash
cp backend/.env.example backend/.env
# 编辑 .env 填入 API Key
```

### 2. 一键启动
```bash
chmod +x start.sh
./start.sh
```

### 3. 访问系统
- 前端: http://localhost:5173
- 后端API: http://localhost:8000
- API文档: http://localhost:8000/docs

## 核心功能

### 分阶段工作流
1. **案件要素提取** - 从材料中提取当事人、事实、时间线
2. **法律关系分析** - 分析法律关系、适用法律、风险点
3. **争议焦点整理** - 梳理核心争议点
4. **文书初稿生成** - 生成完整法律文书
5. **审查与优化** - 多模型交叉审查

### 每阶段支持
- ✅ 展示生成结果
- ✅ 人工编辑内容
- ✅ 修改 Prompt 重新生成
- ✅ 版本历史回溯
- ✅ 流式输出

### 多模型协同
- OpenAI (GPT-4o)
- Claude
- 自定义 API (兼容 OpenAI 格式)

## 技术栈
- 前端: React 18 + Tailwind CSS + TypeScript
- 后端: FastAPI + SQLAlchemy
- 文件解析: pdfplumber + python-docx + pytesseract
